# Visualizer Roadmap

The roadmap is ordered around usable miracles, not infrastructure phases.

## V0 — One AI dreams — IN PROGRESS

Arbitrary shared device/tab audio without microphone; standardized adaptive audio features; OpenRouter PKCE; live model catalog; canonical aesthetic-free prompt; live generation; bounded automatic repair; opaque generated-code sandbox; fullscreen/UI auto-hide/wake lock; local history/favorites; lightweight battle mode.

## V0.1 — Browser truth pass

Real Chrome/Edge/macOS/Windows audio-source matrix; graceful Firefox capability messaging; mobile verification; performance profiling; capture-ended recovery.

## V0.2 — Generation reliability

Richer syntax/runtime smoke tests; model-specific output-length handling without changing the creative prompt; generation cancellation; failure telemetry that never includes music.

## V0.3 — Gallery polish

Instant transitions; collections; recent models; reroll affordance; optional auto-rotation / party mode.

## V0.4 — Many-model ergonomics

Hundreds of models without overwhelming the UI; provider/search filters behind the drawer; new/recent/favorite model shortcuts; nerd-only metadata.

## V0.5 — Dedicated product extraction

Choose final name/domain only after the experience deserves one; extract `/visualizer/` into its own repository unchanged in behavior; dedicated deployment and sandbox origin.

## V1 — Public ship

Production domain; hardened authentication/session behavior; cost/abuse controls; durable synced library only if it materially helps; shareable generation links; polished capability/onboarding; public privacy/security docs.

## V1.1 — Desktop audio

Mac + Windows wrapper using the same runtime; true system-loopback where the OS permits; Spotify desktop, Apple Music, VLC, games, DAWs, and other device audio; same saved visualizers/model experience.
